# Incredible Studio

Turn a blog into slides, and the slides into a narrated video. The app lives in
[`studio/`](studio/README.md).

```sh
yarn setup
yarn dev
```

Then open http://127.0.0.1:4180. What you need installed, how the flow works and
what the checks prove are in [studio/README.md](studio/README.md).
