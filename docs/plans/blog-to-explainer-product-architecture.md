# Technical storytelling product plan

The full specification is now [Technical storytelling studio: human presentation and automatic video](technical-storytelling-product-architecture.md).

Work on `feat/hyperframes-markdown-mvp` and commit coherent, validated changes regularly as `Karthic <Kartronics85@gmail.com>` (author and committer). The full specification defines the commit conventions.

The product supports two first-class creation paths: **Present it myself** and **Generate automatically**. Either can start from the creator's narrative, notes, an article, or a saved base notebook. The specification includes shared brand/theme handling, preserved wireframe bases, Quiver objects, synchronized motion, human rehearsal/recording and presenter direction, local PostgreSQL/MinIO storage, architecture, current gaps, and the development plan.
