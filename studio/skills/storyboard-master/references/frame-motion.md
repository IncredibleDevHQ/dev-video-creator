# Studio note: a motion frame

This frame is a design-led motion piece inside a narrated episode: motion is
the message (`skills/motion-graphics/SKILL.md`). The voice may run under it.

- One continuous design move carries the frame: the shot's signature move,
  built from the cited rules. Kinetic type, a count-up, a chart drawing
  itself, a logo or mark building, a path travelling: not a card of text.
- Type at poster scale, from `frame.md`'s display ramp; few words, each on its
  cue or on the beat.
- Keep it seek-safe and deterministic, as the core contract says; hold the
  final state still.
