# page-master

Draws the pages of a video from an outline, through a coding-agent harness (Claude Code, Kimi, Codex), to the studio's page contract. Entry: `SKILL.md`. Route: `workflows/draw-page.md` — one page per call, from the spec the studio writes (`engine/creative/page-spec.ts`). Only those two files are installed in a run. Checker: `scripts/check_pages.py`, run by the studio on each page when it is submitted. `references/page-contract.md` and the vendored manuals stay as the reference the route was condensed from. The method is adapted from ppt-master, vendored under `vendor/ppt-master/` with its licence — see `VENDORING.md` for what is kept, changed and dropped.
