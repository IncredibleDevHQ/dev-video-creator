# page-master

Draws the pages of a video from an outline, through a coding-agent harness (Claude Code, Kimi, Codex), to the studio's page contract. Entry: `SKILL.md`. Route: `workflows/draw-pages.md`. Contract: `references/page-contract.md`. Checker: `scripts/check_pages.py`. The method is adapted from ppt-master, vendored under `vendor/ppt-master/` with its licence — see `VENDORING.md` for what is kept, changed and dropped.
